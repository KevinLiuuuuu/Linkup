# Linkup

Linkup is a mobile app I built for organising hangouts with friends. You can make chat rooms, run polls to decide what to do, and see where you are on a map, all in one place. It's built with Expo and React Native, with Appwrite handling the backend.

## What it does

- **Accounts:** register and log in with email. Screens are protected, so only logged-in users see the dashboard and only guests see the login pages.
- **Chat rooms:** browse every room, pull to refresh, create your own with a name and description, and jump in to chat.
- **Polls:** after logging in, you get prompted to answer any polls you haven't voted on yet. Poll creators get their own tab showing their polls and who voted what.
- **Maps:** asks for location permission and drops a pin on where you are. Phones use `react-native-maps`, and the web build uses Leaflet instead.
- **Dark theme:** the whole UI is built around a dark look, with a small set of reusable themed components (buttons, cards, inputs, text).

## Tech stack

- [Expo](https://expo.dev) (SDK 53) with [Expo Router](https://docs.expo.dev/router/introduction/) for file-based navigation
- React Native 0.79 and React 19
- [Appwrite](https://appwrite.io) (auth + database) via `react-native-appwrite`
- `react-native-maps` on iOS/Android, `react-leaflet` on web
- `expo-location`, `expo-secure-store`
- TypeScript and JavaScript mixed together (I started in JS and moved some screens to TS)

## Getting started

You'll need Node.js and either the Expo dev client on a device or an iOS simulator / Android emulator.

1. Clone the repo
   ```bash
   git clone https://github.com/KevinLiuuuuu/Linkup.git
   cd Linkup
   ```

2. Install dependencies
   ```bash
   npm install
   ```

3. Start the dev server
   ```bash
   npm start
   ```

Or run it somewhere specific:

```bash
npm run ios       # iOS simulator / device
npm run android   # Android emulator / device
npm run web       # browser
```

The `ios` and `android` folders are generated by Expo and are gitignored, so the first `npm run ios` or `npm run android` will build them for you.

## Backend setup (Appwrite)

The app talks to an Appwrite project configured in `lib/appwrite.js`. To point it at your own backend:

1. Create a project at [cloud.appwrite.io](https://cloud.appwrite.io) and add a platform for the app's bundle ID.
2. Create a database with four collections: `chatRooms`, `messages`, `polls`, and `poll_votes`.
3. Replace the endpoint, project ID, database ID, and collection IDs in `lib/appwrite.js` with your own.

Only public client IDs live in that file. Don't ever put an Appwrite API key in the app.
